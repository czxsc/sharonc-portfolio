## UX Decisions
Optimized for efficiency and engagement. 
1. Homepage Philosophy: If anyone scannign really quickly, just going through main homepage should communicate enough. 2. Motion with purpose: Generally tried to avoid pointless interactions. Instead used for engagement & rewarding. For example, unexpected scrolling effects like coffee pour and window flip to encourage continued scrolling, subtle motion to keep page from being completely static if someone is stopping there to read further (ex. subtle gradient motion behind about, cat switching and word rotation on hero, etc). Compared to inital draft of static website where you just keep scrolling down, much more engaging
